# Send again — last tab or new chat

Highlight more code, press the shortcut again. Pick **Last used tab** to
refill it in a couple of seconds — or **New chat** for a fresh start.
No manual pasting either way.

- First send to a new AI opens its chat and still auto-fills when it loads.
- SelectBeam never presses Enter for you. Review, then submit yourself.
- Switch AI anytime via the palette command **SelectBeam: Send Selection
  to Browser AI**, which always lets you pick.
